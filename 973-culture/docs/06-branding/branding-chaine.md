# Branding définitif — 973 CULTURE – LE PODCAST

> Proposition v1.0 · à valider par la direction du projet.

## 1. Plateforme de marque

| Élément | Proposition |
|---|---|
| Nom | **973 CULTURE** (sous-titre : *LE PODCAST*) |
| Prononciation | « neuf-sept-trois culture » (usage guyanais du code 973) |
| Slogan | **« Les talents d'ici méritent une audience mondiale. »** |
| Promesse | Découvrir, comprendre et faire rayonner la scène urbaine de Guyane et des Caraïbes, avec des faits vérifiés et un vrai point de vue |
| Valeurs | Fierté · Rigueur · Curiosité · Bienveillance critique |
| Ton | Chaleureux, vif, légèrement provocateur, jamais moqueur envers les artistes ; créole guyanais utilisé avec justesse (« tout moun », « Pa mélé », « Mèsi ») |
| Signature éditoriale | La **ligne SOURCE** sous chaque habillage et le **fact-check « confirmé / déclaré »** |

## 2. Identité visuelle

- **Logo** : « 973 » en Inter Display Black, dégradé or (`#FFE39A` → `#F9BF3B` → `#C98A12`), extrusion pseudo-3D brun profond ; « CULTURE » en capitales espacées (approche de +42 %), filet rouge `#D93434` sous le mot. Déclinaisons : logo animé (`scene_logo`), filigrane en haut à droite (`bug`), enseigne néon du décor.
- **Palette** : voir `../03-direction-artistique/decor-et-charte.md` §2.
- **Personnages-hôtes** : Kenzo (vert) et Maëva (rouge), voir `../03-direction-artistique/bible-personnages.md`.
- **Décor signature** : plateau éphémère de la Place des Palmistes ; lumière qui passe de l'heure dorée à la nuit dans chaque épisode (marqueur temporel du format).

## 3. Identité sonore

- Thème original à 96 BPM en la mineur (Am–F–C–G), base trap/dancehall stylisée, motif mélodique de type steelpan, impact sur le logo, whoosh sur les transitions (`production/src/music.py`).
- Déclinaisons : générique (impact + motif), virgules de transition, lit musical sous les dialogues (atténué automatiquement), boucle de fin.
- Règle : aucune musique commerciale ; les morceaux des artistes uniquement avec autorisation écrite.
